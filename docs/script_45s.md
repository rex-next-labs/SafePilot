# SafePilot 숏폼 스크립트 (2차본, 2026-11-03)

- 형식: 9:16 세로, 1080x1920, 약 58초 (공모전 기준 30초~1분)
- 표현 방식: 웹툰풍 모션 코믹. 컷 이미지에 카메라 이동, 효과음, 대사, 자막, SafePilot UI를 얹는다
- 목소리: SafePilot `Vindemiatrix` (아나운서 톤). 장면별 운전자와 정비사 목소리는 각 장면에 적는다
- 슬로건 (확정): 드라이빙의 모든 순간, 믿음직한 파트너
- 제작 코드: 별도 제작 저장소 `src/shortform/` (`comic.py` 컷 생성, `tts.py` 대사, `edit_comic.py` 편집)

## 공통 규칙

1. **운전자 동작에는 이유가 있어야 한다.** 손이 버튼이나 핸들을 만지는 것은 SafePilot 안내를 따르거나 마이크 버튼을 누를 때뿐이다.
2. **SafePilot은 차량을 조작하지 않는다.** 안내하고, 차량 데이터로 결과를 확인만 한다.
3. **운전석 컷에서는 안전벨트를 항상 맨다.**
4. **운전자는 카메라를 보지 않는다.**
5. **차 외관은 실제 사진을 웹툰풍으로 다시 그린다.** 새로 그리면 디자인이 틀어진다. 2027 아반떼는 7번 시도 모두 구형으로 그려져 차종에서 뺐다. 차를 기울여야 하는 경사로 컷은 이미지 모델이 수평으로만 그려서, 차(초록 배경)와 배경을 따로 그린 뒤 13도 기울여 합성했다(`comic.py` composite).
6. **생성 이미지 안에 글자를 넣지 않는다.** UI, 자막, 로고는 편집에서 합성한다.
7. **사고 접촉 장면은 보여주지 않는다.** 실내 충격, 소리, 정지로만 표현한다.
8. **SafePilot이 먼저 알아챈다.** 장면마다 차가 먼저 상황을 감지한다. 운전자가 묻는 것은 SafePilot이 들을 수 없는 내용(정비사의 말)일 때뿐이다.

## 장면 3. 접촉 사고 (0:33~0:53)

- 차종: 제네시스 GV90 / 운전자: 60대 초반 여성, 베이지 카디건 / 목소리 `Gacrux` (음높이는 조정하지 않음. 낮추면 남성처럼 들림)
- 목표: SafePilot이 **먼저 알아채고, 사람부터 챙기고, 차 상태를 읽어서, 당황하면 놓치기 쉬운 것까지 순서대로** 안내한다
